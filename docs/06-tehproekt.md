# 6 Технический проект программного обеспечения

Технический проект программного обеспечения представлен диаграммой компонентов C4 уровня 3
(рисунок 10) для контейнера «API-приложение и worker агента». Компоненты соответствуют модулям
`backend/src/bpmn_assistant`:

- **Входные точки:**
  - HTTP API (`controller/http`) — маршруты `/api/v1` с проверкой идемпотентности;
  - поток событий (`controller/ws`) — WebSocket с прогрессом, черновиком и ревизиями.
- **Сценарии** (`application/workspace`) — создание и импорт диаграмм, запись ревизий с
  проверкой compare-and-set, чаты, выгрузка.
- **Агент:**
  - Worker берёт запросы по аренде;
  - Runner ведёт запрос по этапам и считает бюджеты;
  - Роли агента (`adapter/agents`) хранят промпты и JSON-схемы ролей.
- **Диктовка** (`application/dictation`) — распознаёт фразы и строит по ним черновик.
- **BPMN-модуль** (`service/bpmn`, `adapter/bpmn`):
  - проверка по XSD и правилам графа;
  - раскладка элементов;
  - нормоконтроль;
  - выгрузка.
- **Адаптеры внешних систем:**
  - клиент модели (порт `LanguageModel`) — OpenAI-совместимый API или Claude Agent SDK;
  - клиент распознавания (порт `SpeechToText`);
  - хранилище (порт `UnitOfWork`) — репозитории и транзакции на psycopg 3.

Все компоненты, которым нужна база данных, работают через одно хранилище, поэтому оно показано
общей шиной внизу диаграммы. Компоненты приложения зависят только от портов, адаптеры реализуют
эти порты. Такое разделение (порты и адаптеры) позволяет заменить провайдера модели или базу
данных, не меняя сценарии.
