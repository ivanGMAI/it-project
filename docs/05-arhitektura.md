# 5 Архитектура

Архитектура описана в модели C4 Саймона Брауна:

- человек — тёмная фигура;
- проектируемая система и её контейнеры — синие прямоугольники;
- внешние системы — серые прямоугольники;
- граница системы — пунктирная рамка;
- зависимость — пунктирная стрелка с назначением и технологией в квадратных скобках.

## 5.1 Контекст системы

На рисунке 8 показано окружение schemix:

- **аналитик** работает с системой через браузер;
- **провайдер языковой модели** извлекает факты по JSON-схеме;
- **сервис распознавания речи** переводит фразы диктовки в текст;
- **BPMN-редакторы** получают выгруженные файлы — их открывает аналитик.

## 5.2 Контейнеры

На рисунке 9 система разложена на запускаемые части. Все они разворачиваются одной командой
Docker Compose.

- **Веб-приложение** на React 19 и bpmn-js 18 работает в браузере.
- **Веб-сервер nginx 1.28** раздаёт сборку веб-приложения и проксирует `/api` и WebSocket.
- **API-приложение на Python 3.12 и FastAPI** обслуживает HTTP API и поток событий. В нём же
  работает worker агента.
- **Миграции Alembic** один раз создают схему базы данных.
- **База данных PostgreSQL 16** хранит диаграммы, ревизии, чаты, запросы агенту и журнал
  событий.

Worker агента и API работают в одном контейнере. Очередью служит таблица запросов в
PostgreSQL: worker забирает из неё запрос по аренде.
